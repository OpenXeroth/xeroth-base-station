Build guide

Build a base station.

A shopping list, and every step from opening the boxes to a station sending its recordings to the network. You do not need to know how to program. You will copy and paste some commands, and this guide says exactly what each one does.

1. What you are building

A base station is a satellite-navigation receiver that never moves. Because it stays at a point whose position is known exactly, any error in what it measures must come from the satellites' signals passing through the atmosphere. Other receivers nearby suffer the same errors at the same moment, so the base station's recording lets them remove those errors afterwards.

Yours has four parts:

  • An antenna, fixed outdoors where it can see the whole sky. It picks up the satellites' signals.
  • A receiver board (the simpleRTK2B Lite, which carries a u-blox ZED-F9P chip). It turns the antenna's signals into measurements.
  • A Raspberry Pi 5, a small computer. It records the measurements, turns them into a standard file every ten minutes (called RINEX), and sends those files to the Xeroth network.
  • The station software from this project, which runs on the Pi by itself, day and night, and restarts anything that stops.

2. Before you buy anything

Check that you have, or can get, each of these. The station will not work well without them.

  • A place for the antenna with open sky. A roof, or the top of a pole, with nothing higher around it: no trees, walls or other buildings above the horizon if you can help it. Metal roofs and walls nearby reflect signals and spoil the measurements.
  • A way to fix the antenna so that it cannot move, ever. The station's accuracy is the antenna mount's accuracy. If the antenna shifts by a centimetre, every recording after that is wrong by a centimetre. A bracket bolted to a wall, or a steel pole set in concrete, is right. A tripod or a magnet is not, except for testing.
  • Mains power where the Pi will sit, which can be indoors. The antenna's cable is 2.5 metres long; longer extension cables are listed below.
  • Internet at the site. A network cable from your router is best. Wi-Fi also works. If the internet goes down, the station keeps recording and sends the backlog when it comes back.
  • A computer (Windows, Mac or Linux) for setting the Pi up. You need it only during setup.
  • A Google account, which is how you sign in to this site to join the network.

4. Prepare the memory card

The Pi has no hard disk. Everything it runs lives on the microSD card, and you start by putting a fresh copy of its operating system (Raspberry Pi OS) onto the card from your computer.

  1. On your computer, download and install Raspberry Pi Imager, Raspberry Pi's free program for this.
  2. Put the microSD card into your computer, using the card reader if you need one.
  3. Open Raspberry Pi Imager. When it asks, choose:
    • Device: Raspberry Pi 5.
    • Operating system: Raspberry Pi OS (other), then Raspberry Pi OS Lite (64-bit). "Lite" means it has no desktop, which a station does not need.
    • Storage: your microSD card. Check it is the card, not another drive: everything on it will be erased.
  4. Imager then offers to customise the settings. Say yes, and set:
    • Hostname: basestation. This is the name you will use to reach the Pi from your computer.
    • Username: xeroth, exactly that, in lower case. The station software expects this name.
    • Password: one you will remember. Write it down.
    • Wi-Fi: only if you will not use a network cable. Enter your network's name and password.
    • Your time zone and keyboard layout.
    • SSH: turn it on, with password login. SSH is how your computer will talk to the Pi.
  5. Let Imager write and check the card. When it says it has finished, take the card out.

5. Put it together

  1. The Pi. Follow the leaflet in the case's box. The case's fan has a small cable: plug it into the socket on the Pi marked FAN. Push the microSD card into the slot on the underside of the Pi, contacts facing the board, until it stops.
  2. The receiver. Plug the simpleRTK2B Lite into its USB adapter board, the way ArduSimple's photos on the product page show it. Then connect the adapter to one of the Pi's USB sockets with the USB cable that came with the receiver.
  3. The antenna. Screw the antenna onto its permanent mount, outdoors. Run its cable to the receiver and screw its plug onto the receiver's antenna socket, the small threaded metal one, finger-tight only. If you seal the cable where it passes through a wall or window, leave it a little slack.
  4. Network. Plug the network cable into the Pi and into your router, unless you set up Wi-Fi.
  5. Power. Plug in the power supply last. A red light comes on, then a green light flickers while the Pi starts. The first start takes longer than later ones, because the Pi finishes setting itself up.

6. Connect to the Pi from your computer

From here on you will type, or paste, commands into a window on your computer, and they will run on the Pi. That window is called a terminal.

  1. Open a terminal on your computer:
    • Windows: open the Start menu, type PowerShell, and open it.
    • Mac: open Terminal, from Applications, then Utilities.
    • Linux: open your terminal program.
  2. Type this and press Enter: 
    ssh xeroth@basestation.local
  3. The first time, it asks whether you trust this computer. Type yes and press Enter.
  4. Type the password you chose in step 4 and press Enter. Nothing appears on the screen while you type the password; that is normal.

When it works, the line you type on starts with xeroth@basestation. Everything you type now runs on the Pi.

If it says it cannot find basestation.local, wait a few minutes and try again: the Pi may still be starting. If it still fails, open your router's settings page, find the device called basestation in its list of connected devices, and use the address it shows instead, for example ssh xeroth@192.168.1.42.

Copying and pasting commands. Each grey box below is one or more commands. Copy the whole box, paste it into the terminal and press Enter. To paste: in PowerShell, right-click; on a Mac, Cmd+V; in most Linux terminals, Ctrl+Shift+V. Wait for each box to finish, which is when the xeroth@basestation line appears again, before pasting the next.

7. Install the software

First, bring the Pi's system up to date and install the tools the station needs. The sudo at the start lets a command change the system; it may ask for your password again.

sudo apt-get update
sudo apt-get full-upgrade -y
sudo apt-get install -y git build-essential python3 python3-serial curl

Next, build RTKLIB, the open-source program that reads the receiver and writes the RINEX files. This turns its source code into programs the Pi can run, and puts them where the station looks for them. It prints a lot of text while it works; that is normal.

git clone https://github.com/rtklibexplorer/RTKLIB.git ~/RTKLIB
make -C ~/RTKLIB/app/consapp/str2str/gcc
make -C ~/RTKLIB/app/consapp/convbin/gcc
sudo install -m 0755 ~/RTKLIB/app/consapp/str2str/gcc/str2str \
                     ~/RTKLIB/app/consapp/convbin/gcc/convbin /usr/local/bin/

Then download the station software and make its settings file:

git clone https://github.com/OpenXeroth/xeroth-base-station.git ~/xeroth-base-station
mkdir -p /home/xeroth/base_station/scripts
cp ~/xeroth-base-station/station-configs.example/example.conf \
   /home/xeroth/base_station/scripts/station.conf

8. Check the receiver is seen

Ask the Pi to list its serial devices, which is how the receiver appears to it:

ls /dev/ttyUSB*

It should print /dev/ttyUSB0. If it does, the Pi can see the receiver. Now let the station software set the receiver up the way it needs, which it only has to do once:

python3 ~/xeroth-base-station/payload/scripts/ensure_receiver.py

It prints 115200 when the receiver is ready. If it prints FAILED, see If something goes wrong.

The software expects the receiver at /dev/ttyUSB0. XER2, the network's first station, was built with a separate USB-serial cable wired to the receiver; the USB adapter that now comes with the simpleRTK2B Lite connects to the same port on the receiver. If ls /dev/ttyUSB* prints nothing, unplug the receiver's USB cable, plug it back in, and try again. If it still prints nothing, run ls /dev/ttyACM*, then open an issue or email open@xeroth.ai with what both commands printed, and we will help.

9. Measure the antenna's exact position

A base station's recordings are only useful if the station knows exactly where its antenna is, to a centimetre or better. You measure that once, by recording for a full day and sending the recording to a free government service that works out the position.

Start recording. This command records in the background, so it carries on if you close the terminal or your computer:

nohup str2str -in serial://ttyUSB0:115200:8:n:1:off -out file:///home/xeroth/survey.ubx > /dev/null 2>&1 &

To check that it is recording, run this now and again a minute later. The size of survey.ubx should grow each time:

ls -lh ~/survey.ubx

Leave it recording for at least 24 hours. Do not touch the antenna meanwhile. You can apply to join the network (step 10) while you wait.

Stop recording and convert the file. After 24 hours, connect to the Pi again (step 6) and run:

pkill str2str
cd ~
convbin -v 3.03 -r ubx -f 2 -ti 30 survey.ubx
ls survey.*

The last line lists the files. Next to survey.ubx there is now a file called survey.obs (some versions of RTKLIB call it survey.rnx). That is the day's recording in the standard RINEX format, one measurement every 30 seconds, which is what the processing services use.

Copy it to your computer. Open a second terminal on your computer, without connecting to the Pi, and run this. It copies the file into the folder the terminal is in, usually your home folder:

scp xeroth@basestation.local:survey.obs .

Send it to a processing service. Either of these is free and works anywhere in the world:

  • AUSPOS, from Geoscience Australia.
  • CSRS-PPP, from Natural Resources Canada (it asks you to create a free account).

Upload survey.obs and give your email address. Where the form asks for the antenna height, enter 0: the station needs the position of the antenna itself, not of the ground beneath it. The service emails you a report.

Put the position into the station's settings. In the report, find the antenna's Cartesian coordinates: three numbers labelled X, Y and Z, in metres, each with millions of metres. (Not latitude and longitude.) Open the settings file on the Pi:

nano /home/xeroth/base_station/scripts/station.conf

This opens a simple text editor. Use the arrow keys to move to the line that reads 0.0000 0.0000 0.0000 and replace it with your three numbers, in the order X Y Z, separated by spaces. XER2's line, for example, reads:

4974523.9720 3008024.3060 -2616592.1730

To save, press Ctrl+O and then Enter. To leave the editor, press Ctrl+X.

If you cannot do this step yet, you can still carry on. The station records without it, but leaves the position out of its files, and people using your data will get less accurate results until you add it. If you ever move the antenna, measure it again.

10. Join the network

  1. Apply as a station operator. You sign in with your Google account and tell us where the station is and what you will use it for.
  2. Xeroth reviews every application by hand and emails you the decision.
  3. Once you are approved, sign in to your dashboard. It shows your station's identifier, such as XER3, and its upload key, a long code starting xrx_. The key is shown once only: copy it straight away. If you lose it, you can make a new one on the dashboard.
  4. Put both into the settings file. Open it as before: 
    nano /home/xeroth/base_station/scripts/station.conf
    Change the line STATION_ID=MY_STATION to your identifier, and change the line # UPLOAD_KEY=xrx_... to your key, removing the # at the start. With your own identifier and key, the two lines look like this: 
    STATION_ID=XER3
UPLOAD_KEY=xrx_0123456789abcdef01234567_YourSecretPart
    Save with Ctrl+O and Enter, and leave with Ctrl+X.

The key lets the station upload its own files and nothing else. Keep it private: anyone who has it could upload files as your station.

11. Start the station

Run the installer. It sets everything up to run by itself, now and every time the Pi is switched on:

cd ~/xeroth-base-station
sudo ./install.sh

It prints ten numbered steps and finishes with Install complete and your station's identifier. If it stops with a line starting ERROR, the line says what is wrong; most often the settings file has no STATION_ID= line.

From now on the station:

  • records the receiver continuously, and writes a RINEX file for every ten minutes of the day;
  • uploads each file to the network as soon as it is written, and catches up on any it missed while the internet was down;
  • restarts recording by itself if it ever stops;
  • deletes its oldest raw recordings before the card fills up.

It is safe to run the installer again at any time.

12. Check it is working

Wait about twenty minutes after installing, then connect to the Pi and run:

tail -n 20 /home/xeroth/base_station/logs/automation.log

This shows the station's twenty most recent log lines. When all is well, there are lines ending to https://base.xeroth.ai as XER3 (with your identifier), one for each file it has sent. Your dashboard on this site also shows your station as live, with the time of its last upload.

You can now unplug the screen and keyboard if you used any, close the terminal, and leave the station alone. It needs nothing from you day to day.

The station can also report its health over Tailscale, a private network service, if you install it on the Pi; without Tailscale, that one report does not run, and recording and uploading are unaffected.

13. Keep it up to date

Every few months, connect to the Pi and run these. The first two lines update the Pi's system; the last two fetch the newest station software and reinstall it, keeping your settings:

sudo apt-get update
sudo apt-get full-upgrade -y
cd ~/xeroth-base-station && git pull
sudo ./install.sh

Each new version is listed by its number on the project's GitHub page.

14. If something goes wrong

  • The Pi will not start (no green light). Check the power supply is the 27W one and is switched on at the wall, and that the card is pushed fully into its slot.
  • The receiver prints FAILED, or the log says the receiver is not found. Check the receiver is pushed fully onto its USB adapter, the USB cable is in, and ls /dev/ttyUSB* prints /dev/ttyUSB0 (step 8). Unplug and replug the USB cable, then run sudo systemctl restart gnss-capture.service.
  • The log says uploads fail with HTTP 401. The upload key in the settings file is wrong, or it has been revoked. Make a new station upload key on your dashboard, put it in the settings file (step 10), and run the installer again.
  • The log says uploads fail with HTTP 403. The STATION_ID in the settings file is not the station your key belongs to. Copy the identifier exactly as your dashboard shows it.
  • Anything else. Run tail -n 50 /home/xeroth/base_station/logs/automation.log, copy what it prints, and open an issue or email open@xeroth.ai with it. Never include your upload key.
