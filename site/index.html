OpenXeroth / Base stations

GNSS base stations

Centimetre positioning, from a Raspberry Pi.

A satellite receiver on its own knows where it is to a few metres. A second receiver, fixed at a surveyed point and recording the same satellites at the same time, measures the error the atmosphere caused, and that measurement removes it from the first receiver's record afterwards. Metres become centimetres.

This is open-source software that makes a Raspberry Pi and a u-blox ZED-F9P receiver into that fixed receiver, running unattended. Any station can join the Xeroth network, which keeps every station's recordings and serves them as RINEX files to the people who need them.

Build one, share it, or use the data.

01 / Build

Build a station

A Raspberry Pi 5, a ZED-F9P receiver, a USB-serial cable and a dual-frequency antenna with a clear view of the sky. The software captures continuously, writes a RINEX file every ten minutes, restarts capture if it stalls and deletes its oldest raw files before the disk fills. Apache-2.0.

02 / Join

Add it to the network

Sign in with Google and apply as a station operator. Once Xeroth approves you, your dashboard gives your station its identifier and an upload key. Two lines in the station's configuration and its files go to the network every ten minutes. Operators can read every station's data, not only their own.

03 / Use

Get RINEX data

You do not need a station to use the network. Apply as a data user, say what you need it for, and once approved you get a key that lists the stations and downloads their files for any time in the last 90 days.

What a station records

One file every ten minutes.

FilesRINEX 3.03: a .obs observation file and a .nav broadcast-orbit file for each ten-minute UTC slot, named by the slot's start, for example 202610271540.obs
SatellitesGPS, GLONASS, Galileo and BeiDou on two frequencies each, plus SBAS
RateOne measurement a second
PositionThe station's surveyed antenna position is written into every observation file's header
Kept90 days on the network

How far a correction reaches depends on the distance between the station and your receiver: the ZED-F9P's specified accuracy is 1 cm plus 1 mm for every kilometre between them.

Get RINEX

Apply, then download.

  1. Apply for data access, or as a station operator. You sign in with your Google account and say what you need the data for.
  2. Xeroth reviews each application by hand and emails you the decision.
  3. Once approved, sign in to your dashboard. Your key is shown there once: copy it then.

Send the key as a Bearer token. List the stations:

curl -H "Authorization: Bearer xrx_..." https://base.xeroth.ai/v1/stations

List the files covering your survey, in UTC, up to seven days at a time, then download each one by the url the list gives:

curl -H "Authorization: Bearer xrx_..." \
  "https://base.xeroth.ai/v1/stations/XER2/files?start=2026-10-27T08:00:00Z&end=2026-10-27T10:00:00Z"

curl -H "Authorization: Bearer xrx_..." -OJ \
  https://base.xeroth.ai/v1/stations/XER2/files/202610270800.obs
RequestReturns
GET /v1/stationsEvery station, its position and its last upload
GET /v1/stations/{id}One station
GET /v1/stations/{id}/files?start=&end=The files covering a UTC window of up to seven days
GET /v1/stations/{id}/files/{name}One file

Each key may make 60 requests a minute. Keys can be revoked from the dashboard at any time.
